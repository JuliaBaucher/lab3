Tech architecture (LAB3):
Static frontend hosted on GitHub Pages sends user questions to an AWS API Gateway (HTTP API). The request is processed by a serverless AWS Lambda, which invokes Amazon Bedrock (Titan model) to generate the response. The answer is returned as JSON and rendered here in real time. No state is stored server-side; the UI remains fully decoupled from the model layer.
